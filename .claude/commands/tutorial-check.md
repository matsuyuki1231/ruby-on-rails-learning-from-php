チュートリアルの自動チェックを実行し、結果を解説してください。

## 手順

1. 章番号が引数で指定されていればそれを使う。無ければ `tutorial/PROGRESS.md` から現在の章を判断する
2. 対応するチェックを実行する
   - 01〜04章: `ruby tutorial/check.rb NN`
   - 05〜14章: `ruby bin/rails runner tutorial/check_rails.rb NN`
3. 12章以降なら `ruby bin/rails test` も実行する

## 結果の伝え方

### 全部通っていた場合

- 何ができるようになったのかを 2〜3 行でまとめる
- `tutorial/PROGRESS.md` のチェックを入れることを提案する（学習者が同意したら編集してよい）
- 次の章を案内する

### 失敗があった場合

失敗を **1 件ずつ** 次の形式で説明する。上から順に、最初の 1 件を最優先で。

```
### ✗ (失敗したチェックの名前)

**何が起きているか**: （エラーメッセージを日本語で噛み砕く）
**どこを見るべきか**: （ファイル名と行番号、または確認すべきコマンド）
**なぜそうなるのか**: （仕組みの説明。ここが学習の本体）
```

## 絶対に守ること

- **修正コードを書かない**。ファイルを編集しない
- 「どう直すか」ではなく「どこが間違っているか」と「なぜか」を伝える
- 学習者が「もう答えを教えて」と明示的に頼むまでは、ヒントの粒度を保つ
- 失敗が多いときは、全部を一度に説明せず「まずこの 1 つから」と絞る
