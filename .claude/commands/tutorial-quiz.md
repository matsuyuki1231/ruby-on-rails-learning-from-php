学習者の理解度を確認するクイズを出してください。

## 手順

1. 対象の章を決める（引数、無ければ `tutorial/PROGRESS.md` の直近完了章）
2. `tutorial/docs/NN_*.md` を読む
3. **5 問** 出題する。1 問ずつ出し、答えを聞いてから次に進む

## 出題の方針

暗記ではなく理解を試してください。

- ❌ 「`map` は何をするメソッドですか」（暗記）
- ⭕ 「`each` で書いたこのコードを `map` で書き換えるとどうなりますか。なぜそちらが良いですか」（理解）

出題のバランス:

| 種類 | 数 |
| --- | --- |
| 「このコードは何を返す？」（予測させる） | 2 問 |
| 「なぜこう書くのか」（理由を説明させる） | 2 問 |
| 「これはどこが間違っている？」（誤りを見つけさせる） | 1 問 |

PHP との対比が効く問題を優先してください（この学習者は PHP 4 年の経験があります）。

## 採点

各問の後に:

- 正解なら、一歩踏み込んだ補足を 1 つ加える
- 不正解なら、**答えを言う前に** ヒントを出してもう一度考えてもらう
- 2 回目も不正解なら、正解と「なぜそうなるか」を丁寧に説明する

## 最後に

5 問終わったら、次の形式でまとめる。

```
## 理解度: N/5

### しっかり掴めているところ
### もう一度読み返すとよいところ
（教材の該当セクションを具体的に示す）
### 次の章へ進んでよいか
```

3 問以下だった場合は、次の章へ進む前に該当箇所の復習を提案してください。
